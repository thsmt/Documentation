入力パラメータと固定値

利用者が置き換えるプレースホルダーはオレンジ色、画面上の項目名、選択値、ボタン名は前後に半角スペース相当の間隔を持つ薄いグレーの等幅書体で表示する。確定済みのリソース名、ポリシー名、コマンド名、APIアクション、設定プロパティは通常色の等幅書体で表示する

種類表示例用途
プレースホルダー<CUSTOMER_USER>実行前に利用者が置き換える入力パラメータ
画面項目・選択値NONE画面上の項目名、選択値、ボタン名
利用者作成リソース名EventBridgeSchedulerEC2Stop利用者が作成した確定済みのロール名やリソース名
AWS管理ポリシーAmazonSSMManagedInstanceCoreAWSが名称を定義し、利用者が変更しない値
固定値true手順または仕様によって値が確定している真偽値や列挙値
固定識別子scheduler:GetWidget変更しないAPIアクションやプロパティ名

色分けの判断基準

判断表示記載方法
利用者が環境ごとに入力するオレンジ<ROLE_NAME>などのプレースホルダーで記載
画面上の項目または選択値を記載する薄いグレー画面に表示される名称や値をそのまま記載
利用者が作成した名称を記載する通常色確定済みのリソース名、IAMロール名、IAMポリシー名をそのまま記載
手順や製品仕様で値が確定している通常色true、NONEなど確定値をそのまま記載
AWSが名称を定義している通常色AWS管理ポリシー、サービスリンクロール、APIアクションを正式名称で記載
ℹ️ 判断の基準 実行前に置き換える値、画面上に表示される値、確定済みの名称や固定値を分ける。利用者作成またはAWS管理という所有元だけでは色を変えない

JSONの記載例

json
{
  "Enabled": true,
  "ActionAfterCompletion": "<ACTION_AFTER_COMPLETION>",
  "ManagedPolicy": "AmazonSSMManagedInstanceCore",
  "RoleArn": "arn:aws:iam::<ACCOUNT_ID>:role/<ROLE_NAME>"
}

EnabledのtrueとAWS管理ポリシー名は手順上の固定値として通常色にする。完了後のアクション、アカウントID、ロール名は実行前に置き換えるプレースホルダーのためオレンジ色にする

Scheduleを有効化し、完了後のアクションはNONE、再試行はOFF、DLQはなし、暗号化はデフォルトとする。既存のロールを使用を選択し、EventBridgeSchedulerEC2Stopを指定する

コールアウト

本文から分離して認識させる必要がある情報だけをコールアウトで表示する。通常の説明をすべてコールアウトにしない

ℹ️ 情報 仕様、前提条件、補足、利用できる代替手段を記載する
⚠️ 注意 データ削除、停止、再起動、権限変更など、実行前に判断が必要な影響を記載する
✅ 成功 コマンドの実行結果や設定値が期待する状態になったことを示す
❌ エラー 想定されるエラー、原因、作業を中止する条件、切り戻し判断を記載する

HTML記法

HTML
<div class="callout">
  <strong>ℹ️ 情報</strong>
  仕様、前提条件、補足、利用できる代替手段を記載する
</div>

<div class="callout callout-warning">
  <strong>⚠️ 注意</strong>
  実行前に判断が必要な影響を記載する
</div>

<div class="callout callout-success">
  <strong>✅ 成功</strong>
  設定値が期待する状態になったことを示す
</div>

<div class="callout callout-error">
  <strong>❌ エラー</strong>
  作業を中止する条件や切り戻し判断を記載する
</div>

そのほかの構成要素

構成要素使用する場面
タブWindowsとLinuxなど、同じ目的で方式だけが異なる内容を切り替える
折りたたみ長い実行例、出力例、補足画像など、初期表示では必須ではない内容を格納する
ページ内リンク1ページ内の関連セクションへすぐ移動できるようにする
手順カード順番が重要な操作を番号と短い説明で区切る
チェックリスト作業前後の確認項目や完了条件を漏れなく示す
定義リスト用語、設定名、短い説明を1対1で整理する
別ページ目的、対象読者、実施タイミングが独立する長い手順を分割する
関連ページカード分割したページや次に確認するページを視覚的に案内する
