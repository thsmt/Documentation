Samba

⚡ このページの要約

RHEL 9へSambaを導入し、認証ユーザーだけが利用できるSMB共有を構成する
SELinux、firewalld、Linuxクライアント、Windows ACL、障害切り分けを整理する

1. 構成パラメータの確認

SMB2.1以降を使用し、SMB1、ゲストアクセス、不要なプリンター共有を無効にする

項目パラメータ
サーバー名<SAMBA_SERVER_FQDN>
共有名<SHARE_NAME>
共有パス/srv/samba/<SHARE_NAME>
アクセスグループ<SAMBA_GROUP>
許可する接続元<SMB_CLIENT_CIDR>
最小プロトコルSMB2_10
⚠️ SMB1の禁止

SMB1は古い認証・暗号方式と攻撃面を持つため有効化しない。対応できないクライアントは更新または分離する

2. インストールと起動

2.1 パッケージのインストール

server root
dnf install samba samba-client policycoreutils-python-utils

2.2 バージョンの確認

server shell
smbd --version
rpm -q samba samba-client

2.3 サービスの有効化

server root
systemctl enable --now smb

nmbはNetBIOS名前解決を必要とする旧式クライアント向けであり、DNSで名前解決できる構成では起動しない

3. Sambaユーザーとグループの作成

Sambaユーザーは対応するLinuxユーザーを必要とする。ファイル共有専用ユーザーには対話ログインを許可しない

3.1 共有グループの作成

server root
groupadd <SAMBA_GROUP>

3.2 Linuxユーザーの作成

server root
useradd -M -s /sbin/nologin -G <SAMBA_GROUP> <SAMBA_USER>

3.3 Sambaユーザーの登録

server root
smbpasswd -a <SAMBA_USER>

3.4 登録ユーザーの確認

server root
pdbedit -L
ℹ️ 認証情報の入力

smbpasswdのプロンプトへパスワードを対話入力し、コマンド引数、シェル履歴、構築記録へ残さない

4. 共有ディレクトリの作成

共有グループへ所有権を与え、setgidで新規ファイルのグループを統一する

4.1 共有ディレクトリの作成

server root
install -d -o root -g <SAMBA_GROUP> -m 2770 /srv/samba/<SHARE_NAME>

4.2 SELinuxファイルコンテキストの設定

server root
semanage fcontext -a -t samba_share_t '/srv/samba(/.*)?'
restorecon -Rv /srv/samba

4.3 所有権とSELinuxコンテキストの確認

server shell
ls -ldZ /srv/samba/<SHARE_NAME>

5. Samba設定

自動再読み込み前に構文を検証できるよう、作業用コピーを編集してから正規ファイルへ反映する

5.1 作業用設定ファイルの作成

server root
cp -pi /etc/samba/smb.conf /etc/samba/smb.conf.$(date +%Y%m%d)
cp -p /etc/samba/smb.conf /etc/samba/smb.conf.new

5.2 設定ファイルの編集

server root
vi /etc/samba/smb.conf.new
smb.conf
[global]
    workgroup = <WORKGROUP>
    security = user
    map to guest = Never
    server min protocol = SMB2_10
    load printers = no
    printing = bsd
    printcap name = /dev/null
    disable spoolss = yes
    log file = /var/log/samba/log.%m
    max log size = 1000

[<SHARE_NAME>]
    path = /srv/samba/<SHARE_NAME>
    browseable = yes
    read only = no
    guest ok = no
    valid users = @<SAMBA_GROUP>
    force group = <SAMBA_GROUP>
    create mask = 0660
    directory mask = 2770
    inherit acls = yes

5.3 設定構文の確認

server root
testparm -s /etc/samba/smb.conf.new

5.4 正規設定への反映と再読み込み

server root
mv /etc/samba/smb.conf.new /etc/samba/smb.conf
restorecon -v /etc/samba/smb.conf
smbcontrol all reload-config
systemctl status smb --no-pager

6. SMB通信の許可

firewalldとクラウド側ファイアウォールでTCP 445を信頼済み接続元だけに許可する

6.1 firewalldの有効ゾーン確認

server root
firewall-cmd --get-active-zones

6.2 接続元を限定したSMB許可

server root
firewall-cmd --permanent --zone=<ACTIVE_ZONE> --add-rich-rule='rule family="ipv4" source address="<SMB_CLIENT_CIDR>" port port="445" protocol="tcp" accept'
firewall-cmd --reload
firewall-cmd --zone=<ACTIVE_ZONE> --list-rich-rules

6.3 待受ポートの確認

server shell
ss -lntp | grep ':445'

7. Linuxクライアントからの接続

7.1 クライアントパッケージのインストール

client root
dnf install samba-client cifs-utils

7.2 共有一覧の確認

client shell
smbclient -L //<SAMBA_SERVER_FQDN> -U <SAMBA_USER>

7.3 対話クライアントによる接続

client shell
smbclient //<SAMBA_SERVER_FQDN>/<SHARE_NAME> -U <SAMBA_USER>

7.4 認証情報ファイルの作成

client root
install -d -m 0700 /etc/samba/credentials
vi /etc/samba/credentials/<SHARE_NAME>
credentials
username=<SAMBA_USER>
password=<SAMBA_PASSWORD>

7.5 認証情報ファイルの権限制限

client root
chown root:root /etc/samba/credentials/<SHARE_NAME>
chmod 600 /etc/samba/credentials/<SHARE_NAME>
restorecon -v /etc/samba/credentials/<SHARE_NAME>

7.6 CIFS共有の一時マウント

client root
install -d -m 0755 <MOUNT_POINT>
mount -t cifs //<SAMBA_SERVER_FQDN>/<SHARE_NAME> <MOUNT_POINT> -o credentials=/etc/samba/credentials/<SHARE_NAME>,vers=3.1.1,uid=<LOCAL_UID>,gid=<LOCAL_GID>,file_mode=0660,dir_mode=0770

7.7 永続マウント設定の追加

fstab
//<SAMBA_SERVER_FQDN>/<SHARE_NAME>  <MOUNT_POINT>  cifs  credentials=/etc/samba/credentials/<SHARE_NAME>,vers=3.1.1,_netdev,nofail,x-systemd.automount,uid=<LOCAL_UID>,gid=<LOCAL_GID>,file_mode=0660,dir_mode=0770  0  0

8. Windows ACLを使用する場合

拡張属性を利用できるXFSを使用し、共有定義へWindows ACL用VFSモジュールを追加する。導入前に既存POSIX権限との運用方式を統一する

8.1 共有定義へのACL設定追加

smb.conf
[<SHARE_NAME>]
    vfs objects = acl_xattr
    map acl inherit = yes
    store dos attributes = yes

8.2 設定構文と拡張属性の確認

server root
testparm -s
getfattr -d -m - /srv/samba/<SHARE_NAME>

9. 運用確認と障害切り分け

確認対象確認方法
サービスsystemctl status smb
設定testparm -s
接続smbstatus
ユーザーpdbedit -L
待受ss -lntpで445/TCPを確認
ログjournalctl -u smbと/var/log/samba/を確認
SELinuxausearch -m AVCで拒否を確認

9.1 接続セッションの確認

server root
smbstatus

9.2 警告以上のログ確認

server root
journalctl -u smb -p warning..alert --since today
ausearch -m AVC -ts recent

9.3 一時的なログレベル変更

server root
smbcontrol all debug <LOG_LEVEL>
smbcontrol all debug 1
