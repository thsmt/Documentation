Zabbix 6.0 運用手順

Zabbix Agent 2のOS別導入、ホスト登録、監視項目、メンテナンス、作業前後の確認手順を整理する

1. 対象作業

作業確認観点
Agent導入Zabbix Agent 2のバージョン、Server / ServerActive、ListenPort、PSK設定、サービス状態を確認する
ホストグループ作成運用単位、案件単位、環境単位で識別できる命名にする
メンテナンス設定構築中または作業中の不要通知を抑止するため、対象ホストグループと期間を設定する
ホスト登録Host名、Template、Interface、PSK、Port、所属グループを確認する
最新データ確認Agent Ping、CPU、Diskなどの取得時刻と値が更新されていることを確認する

2. Zabbix Agent 2導入・設定

Agent導入はOSごとに手順が異なります。Red Hat Enterprise Linux 9では公式リポジトリ追加と設定ファイル編集、Windows ServerではMSIインストーラーとウィザード設定を行う

Red Hat Enterprise Linux 9

Zabbix 6.0のRed Hat Enterprise Linux 9向け公式リポジトリを追加します。dnf install だけでは通常Zabbix Agent 2を導入できないため、先に zabbix-release パッケージを導入する

root shell
rpm -Uvh https://repo.zabbix.com/zabbix/6.0/rhel/9/x86_64/zabbix-release-6.0-5.el9.noarch.rpm

dnfのキャッシュを削除し、追加したリポジトリ情報を読み直す

root shell
dnf clean all

Zabbix Agent 2をインストールする

root shell
dnf install -y zabbix-agent2

PSK暗号化を利用する場合は、Agent側でPSKファイルを作成する

root shell
mkdir -p /etc/zabbix/zabbix_agent2.d
openssl rand -hex 64 > /etc/zabbix/zabbix_agent2.d/zabbix_agent2.psk
cat /etc/zabbix/zabbix_agent2.d/zabbix_agent2.psk

PSKファイルの所有者と権限を設定する

root shell
chown zabbix:zabbix /etc/zabbix/zabbix_agent2.d/zabbix_agent2.psk
chmod 600 /etc/zabbix/zabbix_agent2.d/zabbix_agent2.psk

Agent設定ファイルを編集する

root shell
vi /etc/zabbix/zabbix_agent2.conf

主な設定例です。パッシブチェックでは Server、アクティブチェックでは ServerActive を確認します。PSKを利用する場合は、暗号化設定も合わせて記載する

conf
Server=<ZABBIX_SERVER_IP>
ServerActive=<ZABBIX_SERVER_IP>
Hostname=<HOSTNAME>
TLSConnect=psk
TLSAccept=psk
TLSPSKIdentity=<ZABBIX_PSK_IDENTITY>
TLSPSKFile=/etc/zabbix/zabbix_agent2.d/zabbix_agent2.psk
🔐 PSK値の扱い

Zabbix画面に登録するPSK valueは、作成した /etc/zabbix/zabbix_agent2.d/zabbix_agent2.psk の値を使用します。作業記録やチケット本文に平文で残さないようにする

設定値を確認する

root shell
grep -E '^(Server|ServerActive|Hostname|TLSConnect|TLSAccept|TLSPSKIdentity|TLSPSKFile)=' /etc/zabbix/zabbix_agent2.conf
ls -l /etc/zabbix/zabbix_agent2.d/zabbix_agent2.psk

Zabbix Agent 2のバージョンを確認する

root shell
zabbix_agent2 -V

Zabbix Agent 2を自動起動に設定し、起動する

root shell
systemctl enable --now zabbix-agent2

サービス状態を確認する

root shell
systemctl status zabbix-agent2

パッシブチェックを利用する場合は、Agentが10050/tcpで待ち受けていることを確認する

root shell
ss -lntp | grep 10050

Windows Server 2022

Windows ServerへZabbix Agent 2を導入する場合は、Zabbix公式ダウンロードページからWindows向けMSIを取得し、ウィザードでServer、Host名、PSKを設定する

値説明
<ZABBIX_SERVER_OR_PROXY>Zabbix ServerまたはProxyのIPアドレス、またはFQDN。複数ある場合はカンマ区切りで指定する
<HOSTNAME>Zabbixに登録するHost名。Windowsのホスト名と運用上の管理名を合わせる
<ZABBIX_PSK_IDENTITY>PSK identity。例: <HOSTNAME>
<ZABBIX_PSK_VALUE>PSK値。安全な場所で生成し、認証情報管理ルールに従って保管する
  1. 出典：Zabbix公式のAgentダウンロードページを開く
  2. OS Distributionに Windows、OS Versionに対象Windowsバージョン、Hardwareに amd64 を選択
  3. Zabbix Versionに 6.0 LTS、Encryptionに OpenSSL、Packagingに MSI を選択
  4. 表示された6.0系の最新MSIをダウンロードし、対象サーバーで実行
  5. Host nameに <HOSTNAME> を入力
  6. Zabbix server IP / DNS、Server or Proxy for active checksに <ZABBIX_SERVER_OR_PROXY> を入力
  7. Agent listen portは 10050 を指定
  8. PSKを利用する場合はEnable PSKを有効化し、PSK identityとPSK valueを入力
  9. インストール後、services.msc を開き、Zabbix Agent 2 のスタートアップ種類が自動、サービス状態が実行中であることを確認

PSK値を作成する例です。作業端末にOpenSSLがある場合に実行する

shell
openssl rand -hex 64
📍 通信要件 パッシブチェックではZabbix ServerからAgentの10050/tcpへ到達できる必要があります。アクティブチェックではAgentからZabbix Serverへ接続します。Security Group、OS Firewall、Network ACL、経路をあわせて確認する

3. ホストグループ作成

Zabbix管理画面で、監視対象をまとめるホストグループを作成する

  1. Zabbix管理画面にサインイン
  2. 「設定」から「ホストグループ」を開く
  3. 「ホストグループを作成」を選択
  4. グループ名に、環境や案件を識別できる名称を入力
  5. 作成後、ホストグループ一覧に表示されることを確認
命名例用途
<CUSTOMER_CODE>.<PROJECT_CODE>_<CUSTOMER_NAME>_<PROJECT_NAME>顧客、案件、環境をまとめて識別する場合
<PROJECT_NAME>-<ENV>小規模な検証環境や学習環境で簡潔に識別する場合

4. メンテナンス設定

構築中や運用開始前に不要な通知が出ないよう、対象ホストグループにメンテナンス期間を設定する

  1. 「設定」から「メンテナンス」を開く
  2. 「メンテナンス期間の作成」を選択
  3. 名前に作業内容、日付、作業者がわかる名称を入力
  4. 開始日時と終了日時を設定
  5. 対象に、作成したホストグループを指定
  6. 保存後、メンテナンス一覧に表示されることを確認
命名例用途
<PROJECT_NAME>_運用開始前のため静観_yyyymmdd(<OPERATOR>)運用開始前の構築期間を静観する場合
<PROJECT_NAME>_計画作業_yyyymmdd(<OPERATOR>)計画作業中の通知抑止として使う場合

5. ホスト登録

Agent導入後、Zabbix管理画面で監視対象ホストを登録する

  1. 「設定」から「ホスト」を開く
  2. 「ホストの作成」を選択
  3. Host nameに <HOSTNAME> を入力
  4. Templatesに対象OS向けのアクティブエージェント用テンプレートを追加します。例: 基本監視 Linux (Activeエージェント2)、基本監視 Windows (Activeエージェント2)
  5. Groupsに作成済みのホストグループを追加
  6. InterfacesでAgentを追加し、IP addressに対象サーバーのプライベートIP、Portに 10050 を指定
  7. 暗号化を利用する場合は、Agent側と同じPSK identityとPSK valueを設定
  8. 保存後、ホスト一覧でStatusが有効になっていることを確認

6. 最新データ確認

ホスト登録後、最新データが取得されるまで1から5分程度待ってから確認する

  1. 「監視データ」から「最新データ」を開く
  2. Hostに <HOSTNAME> を指定してフィルタ
  3. Agent Ping、CPU使用率、Disk使用量などのアイテムが表示されることを確認
  4. Latest checkの時刻が更新され、値が取得されていることを確認
