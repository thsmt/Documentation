AWS

CloudFormation 運用手順集

デプロイ方法、変更セット、ロールバック、ドリフト検出、削除前確認などを整理する

AWS CLI 特殊対応

CLI/APIでしか変更・切り戻し・復旧できない運用手順をまとめる

AWS CLI コマンドリファレンス

認証確認、Security Group、Prefix List、SNSなど、日常運用で使う基本コマンドを整理する

EventBridge Scheduler

EC2、RDS、WorkSpacesなどを、AWS APIのスケジュール実行で停止・起動する設計と手順を整理する

Amazon WorkSpaces

WorkSpacesのディレクトリ登録、Web Access、カスタムイメージ、Cost Optimizer、トラブル対応を整理する

Amazon SES SMTPリレー

カスタムMAIL FROM、Route 53レコード、PostfixからSES SMTPへのリレー、送信テストを整理する

Amazon SES 配信監視

Configuration Set、イベント通知、レピュテーション、サプレッションリスト、VDMを整理する

Amazon RDS Blue/Green Deployments

インプレース更新との差分、仕組み、制約、切替、監視、復旧計画、本番適用手順を整理する

AWS Certificate Manager (ACM)

ACM証明書の有効期間と更新方式を整理し、エクスポート可能な証明書をRHEL 9.8上のApacheへ配置してTLS通信を確認する

OS／ミドルウェア

Red Hat Enterprise Linux 9

基本パッケージ導入、logrotate設定、ミドルウェア別logrotate設定の注意点を整理する

Red Hat Enterprise Linux 10

x86-64-v3、RHUI / RHSM、DNFモジュール廃止を踏まえた初期構築手順を整理する

Amazon Linux 2023

Amazon Linux 2023の初期設定、追加パッケージ、rsyslog、cron、リリース固定を整理する

Windows Server 2022

EC2起動、RDP接続、ローカルユーザー作成、OS初期設定、Windows Updateの確認観点を整理する

Windows Server 2025

Windows Server 2022との差分、Credential Guard、OpenSSH、SMBセキュリティを含む構築手順を整理する

Windows Server 2016 インプレースアップグレード

EC2上のWindows Server 2016を、インストールメディアでWindows Server 2025へインプレースアップグレードする手順を整理する

Apache

Apacheの構築・運用で必要なTLS、SELinux、認証、リバースプロキシ、ログ調査を整理する

Apache SSL終端構築手順（自己署名証明書）

EC2上のRHEL 9.8でApacheへ自己署名証明書を設定し、HTTPからHTTPSへのリダイレクトとSSL終端を確認する

MariaDB

RHEL 8 / 9でのバージョン選択、設定、ユーザー管理、バックアップ、クライアント更新を整理する

PostgreSQL

RHEL 8 / 9でのバージョン選択、初期化、認証、ロール管理、バックアップ、クライアント更新を整理する
